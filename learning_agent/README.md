# learning_agent: briefs for the LearnHarness teacher (/learning)

One brief per lesson of CS 568 Speech Processing. A brief tells the teacher agent which files to read (absolute paths), what the
lecture covers, which slide errors are known, and how to use the check questions and the multiple-choice quiz.

## How to use

Open LearnHarness, start a **Teach** session (or **Practice** for questions only) and paste:

```
Teach me <lesson>. First read the brief at <path of the brief> and the files it lists, then probe what I already know.
```
